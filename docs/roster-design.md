# Proposed roster, replacement and league loop

Design recorded from the player's request; **not implemented**. The current game still has three active Founders and one basic prosthetic crafting recipe.

A veteran should remain a character even when their current build no longer fits the player's plan. Separate the **owned roster** from the **active squad**.

| Choice | Purpose | Identity/history |
| --- | --- | --- |
| Bench | Try a recruit or another combination | Keep the complete veteran |
| Rebuild | Treat wounds and replace/change prosthetics | Keep service history and scars |
| Retrain | Change combat class for a different role | Keep personality/history; class training needs its own rules |
| Retire | Permanently stop fielding a fighter | Keep a hall-of-veterans record |

Extra reserve slots can cost earned in-game currency. League rules determine active-squad capacity equally for both opponents; owning more reserve slots does not let one side bring an unlimited force. Match rewards can feed separate roster/recruitment currency and battle salvage used for prosthetics/equipment.

First implementation slice: active squad, bench, recruit, class selection and swapping a fighter into a legal active slot. Keep the existing King/Queen/General founding rule. Decide how leadership seats transfer when a commander is benched before changing their saved title contract. Recruitment and transfers must refer to stable fighter IDs rather than the current three-slot array indices.

Next: league advancement and roster-slot pricing. Later: retirement/trainer benefits, morale, long-term wear, higher crafting tiers and richer class combinations. Do not implement forced aging decline or delete an injured veteran merely because they are currently weaker.

A reserve roster requires a deliberate save migration from today's fixed three-member squads. Old identities, experience, appearance, wounds, crafting state and records must survive it.
