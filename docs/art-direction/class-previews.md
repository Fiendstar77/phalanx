# Core class appearance previews

Actual game screenshots of the new bases, starter outfits and weapons.
These are early geometric accessories; fabric folds, texture painting and
more detailed silhouettes remain further art work. Skin/dye choices in these
screenshots are individual cosmetics, not class restrictions.

Rock Thrower and Paladin retain their earth/gold palettes and sling/hammer gear.

The 3D style is a first interpretation of [the supplied targets](README.md).
The facial rigs preserve the artist's sculpt and add actual brows, lids, mouth
interiors, teeth and tongue; they are not a finished match to the drawings.
