# Shared rules direction

The intended common rules foundation for Phalanx, Zeitgeist, and future games is **Guillaume Heinerth's universal game system**, a personal hybrid drawing from **Steve Jackson's GURPS** and **Rolemaster**. Settings, art direction, interfaces, and cinematic presentation can differ between games. One framework across different worlds is the intended use described in the [official GURPS introduction](https://www.sjgames.com/gurps/books/basic/characters.pdf).

This is the user's cross-project design direction, established October 24, 2026. Phalanx's current autonomous combat and progression remain its existing prototype mechanics. The next rules pass will map attributes, skills, resolution, injury, equipment, and advancement to that common foundation. The presentation changes in this pass do not implement that conversion.

Wire-fu choreography, weapon trails, impact effects, camera cuts, and musical intensity express resolved events. They do not themselves authorize hits, extra damage, movement, progression, or changes to a fighter's saved state.

Phalanx is the first intended showcase, presented as a game by Guillaume Heinerth. The game projects are intended to be developed and presented personally by Guillaume Heinerth, outside Cognis 11 Inc.
